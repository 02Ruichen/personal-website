三、逐个技能

01 intern-onboarding-checklist 入职资料核查表（也是通用「名单 + 待填列」生成器）

结构：第 1 行合并标题；第 2 行表头 序号 / 单位 / 岗位 / 姓名 / 邮箱 / 纸质版资料核查情况 / 电子版资料核查情况；人员行（单位等同值列自动纵向合并）；表尾填写说明 + 核查人/核查日期；A4 竖向、锁 1 页。

```bash

python build_checklist.py --roster "<录取名单.xlsx>" --out "入职资料核查表.xlsx" \

--unit "保利文化集团股份有限公司" \

--title "2026澳门青年·实习计划文化艺术专项入职资料核查表"

```

常用参数：

  • --cols：改列，如 --cols "序号,单位,处室,岗位,姓名,邮箱"（要分处室的专项把处室加回来）。
  • --checks / --no-checks：改或去掉核查栏；只给一列时该列自动加宽。
  • --dropdown "列名=选项1,选项2"：加 Excel 下拉；--fill "列名=固定内容"：整列逐行填同一句话。两者可重复传。
  • --unit / --dept：名单里没有单位/处室列时的固定值；--header-row：表头定位错了手动指定；--landscape、--row-height：列多或要留手写空间时调。

硬规则：人员只来自名单，不自行增删；两列核查栏留空（那是现场勾的）；必须一页。

坑：名单常有两行表头（别把标题行当表头）；邮箱列太窄会折行；Excel「适应 1 页」只会缩小不会放大。

--sheet "银行账户信息收集" --no-checks --landscape --row-height 34 --note "" \

--levels 公司,岗位,姓名 要三层；--no-number 去掉公司序号前缀；--number-people 给人员文件夹也加全局序号；列名自动按表头认，认不出用 --unit-col/--post-col/--name-col。

04 attendance-table-builder 考勤表制作

用途：把「录取名单 → 各单位空表 → 逐月滚动」标准化。两种活：从名单建初始表；拿上月空表滚下月（只换日期区间）。

结构框架（所有单位一致，只有日期区间不同）

位置内容 第 1 行标题，如 2026年7月27日至8月21日澳门青年实习计划考勤情况统计表 第 2 行单位名称：×××（左）＋制表日期：2026年X月X日（右） 第 3–6 行表头：序号／姓名／岗位／日期（含月份表头、日期数字、星期）；出勤天数、请假天数纵跨 3–6 行 第 7 行起人员行（周末列打「休」、浅绿底） 表尾考勤员（靠左）／审核员（靠右）、空行、备注：及 3 条说明

命令（脚本 scripts/attendance_tables.py，只用标准库，直接改 xlsx 内部单元格、不动格式）

```bash

第 0 步：先看表结构，别凭印象写死行列

python scripts/attendance_tables.py survey "<考勤表.xlsx>"

活 A：上月空表 → 下月空表（只换日期区间）

python scripts/attendance_tables.py next-month --template-dir "<上月空表文件夹>" --out "<本月空表文件夹>" \

--range "格力电器=8.26-9.22" --range "中证鹏元=8.31-9.25" --made-date 2026-09-10

活 B：从录取名单建各单位空表

python scripts/attendance_tables.py from-roster --roster "<录取名单.xlsx>" \

--template-dir "<空表模板文件夹>" --out "<输出文件夹>" --range "格力电器=8.26-9.22"

核对改动范围：应只有标题、制表日期、月份表头、日期行、星期行、人员行周末列

python scripts/attendance_tables.py diff "<上月表>" "<本月表>"

```

三条硬规则

  • 按单位分表：同单位的人在同一张表上，多家单位就多个 xlsx（一单位一个文件）。
  • 框架一致，只换日期：字体、行高、列宽、边框、合并一律保持原样。
  • 人员顺序：建表时 单位顺序 → 岗位顺序 → 名单顺序；滚动时以上月表顺序为准（单位可能自己调过）。

容易踩的坑

  • 星期必须按真实公历写，模板里的历史错误别照抄（例：7 月 29 日标成「一」，实际是周三）。
  • 月份表头按真实月份分界；某个月只有 1–2 列时整行改短标签（8月），否则窄列里长标签会折行。
  • 周末列的位置由区间起始星期决定，区间一变，「休」落在哪些列要重算（人员行的「休」也要跟着挪）。
  • 不要用 openpyxl 另存这些表（会重排样式、丢页面设置）。
  • 输出放在当月目录下的「空表」子文件夹，不要散落在项目根目录。

做完必查：diff 比对改动范围 → 打开/渲染看一眼对齐 → 天数、人数、单位名称再核一遍。

> 明细规则见 参考文档\04 考勤表表结构说明.md。

05 attendance-unregistered-leave 请假未登记统计

用途：从一批单位考勤表中找出「请假未登记」的人，并推算具体哪几天没登记，出一张汇总表。

第 0 步（必做）：先分析每个文件的实际框架，再动手。绝不写死行列号——备注列可能在 AG(33)、AI(35)、AO(41)……列错整套结果就错。

自适应定位规则：

  • 表头行：前 10 行内找同时含「姓名」和「日期」的一行。
  • 月份行：表头行下一行；值是文本（7月）或日期序列号（46235 → 2026 年 8 月）都见过，空列继承前一列。
  • 日期行：月份行下一行；有数值的连续列就是日期列（区间因单位而异）。
  • 姓名列：表头「姓名」所在列。
  • 出勤／请假列：优先按表头文字定位；没有表头就按「最后日期列 +1 = 出勤、+2 = 请假」推。
  • 登记情况备注列：按内容扫描，从日期列之后找第一个含「未登记／已登记／登记」的单元格。
  • 必须读完整张表的所有数据行（有人排到第 14 行）。
  • 文件既可能是 .xlsx，也可能是老式 .xls。

```bash

python scripts/extract_unregistered.py "<考勤表文件夹>"

输出：单位 | 姓名 | 未登记日期 | 类型 | 天数 | 备注，并标记是否需人工复核

```

判读要点

  • 未登记日期 ≠ 全部请假日期。8.18-8.21未登记 只对应 8/18–8/21；除了8.21，剩下未登记 则相反。
  • 备注只写「未登记」没写日期时不要猜：把该人请假日全部列出，标「请人工确认是否全部未登记」。
  • 单位名称以文件名和表内标题为准，同名单位只合并一次；不改动原始考勤表。

汇总表建议列：序号、单位、姓名、未登记日期、请假类型、未登记天数、请假天数、出勤天数、备注（日期写「8月18日、8月19日」这种中文写法）。

> 明细规则见 参考文档\05 请假未登记判读规则.md。

06 intern-salary-audit 薪资核算（实习生薪资核对与统计）

用途：把「考勤表 → 补贴明细表 → 银行报盘表」这条每月流程跑完，只读不破坏原公式。（名字里写的是「薪资核对」，实际就是每月薪资核算这一块。）

计算规则

  • 事假：整天扣 200，半天扣 100；病假：不扣（津贴补回）。
  • 满勤基数 base = 4000（20 天 × 200）。
  • AF 应发 = 出勤天数 × 200 + 病假补偿（病假整天 +200、半天 +100）。
  • 缺勤天数 = (base − AF) ÷ 200（这样病假自然不计，事假、离职、出勤不足会计入）。
  • 符号：√ 出勤、休 休息、△ 病假、▲ 事假、X 旷工、﹡ 迟到早退、0.5△／△半天 半天病假。

```bash

python intern_salary_audit.py probe <明细或报盘.xlsx/.xls> # 0) 先看列位置（换框架先跑）

python intern_salary_audit.py check <考勤表文件夹> # 1) 核对每人 出勤/请假/病假/事假/AF应发/缺勤

python intern_salary_audit.py fill-detail <考勤表文件夹> <8月明细.xlsx> --backup # 2) 缺勤写进明细 H 列

python intern_salary_audit.py fill-report <8月明细.xlsx> <报盘表.xls或xlsx> <输出.xlsx> # 3) 实发匹配到报盘金额列

python intern_salary_audit.py check-bank <8月明细.xlsx> <报盘表> # 4) 银行账户核对

python intern_salary_audit.py check-sample <考勤表文件夹> <明细> <报盘> --n 8 # 5) 随机抽查

```

换框架只调参数，不改代码：fill-detail 的 --sheet/--name-col/--unit-col/--absent-col/--start-row/--skip-units/--base；fill-report 的 --detail-amount-col/--report-name-col/--amount-col/--header-rows；check-bank 的账号、跨行标识、行名列；check-sample 的 --n/--seed。

关键判定

  • 半天：符号含 0.5／半天／上午／下午，或格为 下／上／上午请假，按 0.5 算。
  • 请假天数 AE = 事假 + 病假；缺勤天数只取事假部分。
  • 明细里没有考勤的人（产发局等）留空，不臆造金额。
  • 特殊补扣（如 AF 公式含 -(200*1.5)）会让缺勤天数含补扣折算，要在备注写明。
  • 报盘 .xls（旧版 OLE/BIFF8）用脚本内置解析器读，只读不改，输出 .xlsx。
  • 账户核对：报盘的账号要与明细一致，「跨行标识」与「银行类型」吻合（建设银行 → 跨行 0，其它 → 1）。
  • 旧版 .xls 报盘的金额列在底层可能是坏值/异常大数，不要直接读，要向用户要报盘截图或确认过的文件。
  • 最后一步 check-sample：抽 n 人核对 考勤 AF = 明细实发 = 报盘金额，全一致才算通过。

> 明细规则见 参考文档\06 薪资判读规则.md。
